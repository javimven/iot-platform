# Plataforma de Monitorización IoT

Plataforma SaaS multitenant de monitorización IoT (sector inicial: agro/ambiental), con backend NestJS, frontend Flutter (web/Android/iOS) e ingesta de telemetría vía MQTT desde gateways de campo (LoRa + GPRS/Ethernet).

Este repositorio se está construyendo fase a fase. No contiene todavía código de producción.
